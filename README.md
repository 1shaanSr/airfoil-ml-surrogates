# Airfoil surrogate study

Code and results for "Machine-Learning Surrogates for Airfoil Aerodynamics: Accuracy, Extrapolation, and the Role
of Known Physics: A Case Study with a Panel-Method Testbed" (preprint: `paper.pdf` in this repo). A random forest
and linear regression are trained on airfoil lift and drag data generated by a panel method and a simple drag
estimate, and evaluated inside and outside the training range.

Tested with Python 3.13 and the versions in `requirements.txt`. All computations are deterministic (fixed seeds).

## Physics model (`code/`)
- `naca_geometry.py` - NACA 4-digit camber line and thickness (open trailing edge, cosine spacing).
- `panel_method.py` - constant-strength source + single-vortex panel method with Kutta condition (Hess-Smith type).
- `drag_model.py` - `Cd = Cf * FF(t) * Swet/c + k * Cl^2` at Re = 1e6 (assumed constants, see the paper).

## Reproduce (run from `code/`)
```
python3 generate_dataset.py       # -> data/main_dataset.csv, data/extrapolation_dataset.csv
python3 train_surrogate.py        # -> data/surrogate_results.csv
python3 extra_analysis.py         # repeated splits, held-out shapes, learning curve, importance, residuals, two-stage model
python3 reliability_analysis.py   # tree spread vs error, input-range check
python3 verify_exact_solution.py  # Karman-Trefftz exact-solution check -> data/kt_exact_check.csv
python3 make_all_figures.py       # figures -> figures/
python3 build_tables.py           # LaTeX tables from the saved results -> data/tables_generated.json
```

## Verification scripts (print PASS/FAIL and assert the numbers quoted in the paper)
- `verify_physics_claims.py` - symmetry; source and vortex influence coefficients vs numerical integration; thin-airfoil
  zero-lift angle; lift from pressure integration vs circulation; lift-curve slope.
- `verify_exact_solution.py` - panel method vs the exact Karman-Trefftz lift slope.
- `verify_sensitivity_claims.py` - open/closed trailing-edge sensitivity; negative drag from linear regression.

## Data
`data/` holds every result file the paper's tables and figures are built from.
